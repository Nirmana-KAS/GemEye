# GemEye — Automated Blue Sapphire Colour Grading

A smartphone macro lens-based automated colour grading system for 1-5 mm cut and polished blue sapphires, using the GEMCLOUD 7-grade standard, device-independent CCC calibration, and cloud-deployed ensemble machine learning.

## Tech Stack
- **Mobile:** Flutter (Dart)
- **ML:** EfficientNet-B0 + Random Forest Ensemble
- **Cloud:** AWS Lambda + API Gateway + S3
- **Database:** MongoDB Atlas
- **Auth:** Firebase Authentication
- **Calibration:** 6-patch CCC card + 3x3 CCM

## Colour Grades (GEMCLOUD Standard)
1. Dark (Midnight Blue)
2. Deep (Twilight Blue)
3. Vivid (Royal Blue)
4. Intense (Intense Cornflower)
5. Medium Intense (Cornflower Blue)
6. Light (Pastel Blue)
7. Very Light (Near-Colourless)
